DISCORD ADMIN COMMANDS

Admin actions, without the syntax.

These tools write directly to the bot’s live database. Changes are logged.

/give

/admin give · /admin give_official

/admin restore_cards

Restore official cards

/admin remove_by_name

Remove by name

/admin clear_inventory

Clear inventory

/store refresh

Refresh player store

Queues a force-refresh for the Discord store worker. The new offers go live during its next five-minute check.
